What is NutriInfo?

🤖
Groq + Llama 3 Backend

NutriInfo uses Groq's free API with Meta's Llama 3.3 70B model. Your API key stays safely in the backend .env file — never exposed to the browser.

📊
Complete Nutrition Data

Calories, macros, fiber, 8 vitamins and minerals, health score (1–10), smart badges, daily goal comparisons, and personalized diet tips for every food.

🗂
Category Browser

80+ curated foods across 7 categories — Fruits, Vegetables, Proteins, Grains, Dairy, Nuts, and Legumes. One click sends any food to the AI analyzer.

📋
Nutrition Log

Every analyzed food is saved to your session log with cumulative calorie and macro tracking. Delete individual entries or clear the whole log anytime.

🔒
Secure Architecture

API key lives in a backend .env file — never in client code. The Express backend proxies all AI requests securely. Frontend only talks to your own server.

🚀
Deploy Anywhere

Deploy the backend to Railway, Render, or Fly.io for free. Host the frontend on Vercel or Netlify. Full deployment guide in README.md.
